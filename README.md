# CarmondaNews

Прототип новостного сайта: поиск новостей через NewsAPI, просмотр результатов и добавление новостей в избранное (хранится в `localStorage` браузера).

## Описание

CarmondaNews — простое веб-приложение на Node.js/Express, которое по ключевому слову запрашивает новости у [NewsAPI](https://newsapi.org/) и показывает их карточками на странице. Любую новость можно сохранить в «Избранное» (переключатель ♡/♥) — сохранённые новости хранятся локально в браузере и остаются после перезагрузки страницы.

API-ключ NewsAPI хранится только на сервере (в `.env`) и никогда не передаётся клиенту — браузер обращается к собственному серверу (`/api/news`), а сервер уже сам делает запрос к NewsAPI с ключом.

**Функционал:**
- Просмотр новостей по поисковому запросу
- Добавление/удаление новостей из избранного (localStorage)
- Поиск новостей по ключевому слову

**Стек:** Node.js, Express, axios, dotenv — на бэкенде; HTML/CSS/JS — на фронтенде.

## Как скачать проект

```bash
git clone https://github.com/jaam8/special-journey.git
cd special-journey
```

## Как запустить проект

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Получите бесплатный API-ключ на [newsapi.org/register](https://newsapi.org/register).

3. Создайте файл `.env` в корне проекта на основе `.env.example` и вставьте свой ключ:

   ```
   NEWS_API_KEY=ваш_ключ_от_newsapi
   PORT=3000
   ```

4. Запустите сервер:

   ```bash
   npm start
   ```

   Либо в режиме разработки (с автоперезапуском при изменении файлов):

   ```bash
   npm run dev
   ```

5. Откройте в браузере [http://localhost:3000](http://localhost:3000).

## Деплой на Render

В проекте есть `render.yaml`, поэтому деплой делается через Blueprint:

1. Запушьте проект в GitHub.
2. На [render.com](https://render.com) выберите **New → Blueprint** и укажите этот репозиторий.
3. Render подхватит `render.yaml` сам (билд: `npm install`, старт: `npm start`).
4. При создании сервиса укажите переменную окружения `NEWS_API_KEY` (значение из `.env`) — `PORT` Render выставит сам.
5. После деплоя сайт будет доступен по адресу вида `https://carmondanews.onrender.com`.
